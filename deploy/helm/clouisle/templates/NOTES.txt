Sandbox workers run once per eligible node with isolated hostPath persistence.
Restrict nodes with sandboxWorker.nodeSelector; add sandboxWorker.tolerations for
dedicated tainted nodes. The default path is isolated by namespace/release.
Host paths must be writable by the sandbox worker; node/disk loss does not
preserve workspaces. Keep sandboxWorker.localDataPath exclusive to this install.
