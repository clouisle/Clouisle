## 工具调用可观测性

### 目标
记录**模型当次实际收到的工具输出**，并与前端/引用使用的结构化结果并存，供按需排查；同时不让全文进入指标聚合表、列表接口或会话历史查询。

### 数据与性能边界

| 项 | 决定 |
|---|---|
| 工具消息 `content` | **不变**，仍存结构化展示数据，避免历史查询变大 |
| 新表 `observability_tool_payloads` | 一行/工具调用，存 `display` 与 `model_input` 全文 |
| 列表/汇总接口 | 只返回轻量元数据（字节、hash、eof、续读、partial），不加载正文 |
| 详情接口 | 单条按需读取，前端展开工具 span 时才请求 |
| 写入 | 工具热路径一次小 upsert，0.1s 上限，失败仅 debug 日志，不影响执行 |
| 超限 | 超过 256 KiB 的正文不存，标记 `partial` 并保留字节数 |
| 保留 | 随 `ObservabilityRun` 过期批次一起删除，不新增后台任务 |
| 历史数据 | 不回填；缺失时详情明确显示“未记录” |

### 展示

- 工具 span 行显示：`模型 2.8 KB · 原始 5.1 KB`、未读完/部分记录/错误标记。
- 展开后默认 **模型输入** 页签，原样展示 `llm_result`（带行号正文、游标）。
- 次级 **原始数据** 页签展示 `display_result`，供引用与渲染排查。
- 不以重算结果冒充当次输入；旧记录明确标注未记录。

### 验证
- 后端：payload 存储/读取、超大截断标记、重复调用更新单行、continuation 元数据、过期级联删除、loop 实际写入的模型文本与展示文本分离。
- 前端：展开工具 span 前不请求 payload；展开后展示模型正文；类型、lint、i18n 通过。
