# Colsland 中央分块编辑界面设计

## 背景与目标

在独立 Colsland 页面中央提供类似 Notion 的分块文档编辑界面。用户明确选择本轮仅做界面：内容只在当前页面内存在，刷新或离开即丢失；不实现项目、持久化或协作。界面必须显著提示内容不保存。

## 总体设计

使用已有的主题样式与 UI 按钮，在页面中构建居中纸张式文档区域。标题和各文本块可编辑；提供段落、标题、列表和待办块的添加、类型选择、删除与键盘操作。采用本地 React 状态与 textarea，不引入新的富文本引擎或模拟服务；每个块为纯文本，避免以简易 contenteditable 冒充完整富文本编辑器。

## 实施计划

### 阶段一：分块编辑界面
- **文件**：`frontend/app/colsland/page.tsx`、`frontend/app/colsland/_components/block-editor.tsx`。
- **逻辑**：呈现标题、未保存提示、分块菜单及可编辑文本块；支持添加、删除、类型切换、待办勾选；Enter 新增块，空块 Backspace 删除并回到前块。文本域自适应高度，长文可滚动；不干扰右下角机器人。
- **验证**：实际 DOM 输入、添加、类型切换、删除、键盘操作及未保存提示；移动宽度结构由样式约束，视觉需授权浏览器验证。

### 阶段二：国际化与回归
- **文件**：`frontend/i18n/{en,zh}/platform.json`、`frontend/i18n/types/platform.ts`、编辑器与页面测试、`CHANGELOG.md`。
- **逻辑**：同步中英文文案、无障碍名称及页面认证测试；不提供保存状态或项目数据。
- **验证**：Bun 针对性测试、TypeScript、ESLint、翻译检查；直接渲染编辑器并检查 DOM 操作。

## 测试策略

- 正常：编辑标题和内容、添加各类块、切换类型、勾选待办。
- 边界：仅剩一个块时不删除最后编辑入口；空块退格不误删非空内容；刷新／重新挂载内容不保存。
- 回归：登录保护、机器人入口和现有页面布局。
- 不启动服务和浏览器，无法验证实际视觉与跨浏览器输入法体验。

### 验证结果

- 页面和组件测试 3 项通过；事件处理器覆盖块类型、待办和删除，页面测试覆盖认证与机器人入口。
- 独立 Happy DOM 冒烟在初始化 DOM 后加载 React，真实派发输入和键盘事件，验证输入、Enter 拆分和空块 Backspace。原组件测试中 DOM 初始化较晚，原生键盘事件未触发，故改用项目已有的处理器调用测试模式；不将它视为浏览器验证。
- TypeScript、ESLint、双语翻译检查通过。未启动浏览器，视觉和真实输入法效果未验证。


## 风险与缓解

- 纯文本块不具备富文本、拖放或复杂粘贴能力；界面不宣称这些功能。若后续需要完整 Notion 编辑体验，应另选成熟编辑框架并设计文档存储。
- 用户明确选择不保存：常驻提示刷新或离开后丢失，避免误认自动保存。
- 回滚：移除编辑组件与文案，恢复页面中央空白；无数据库迁移。
