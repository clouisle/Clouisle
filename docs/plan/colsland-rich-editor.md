# Colsland 富文本文档编辑器设计

## 背景与目标

替换仅支持纯文本的 textarea 分块，实现真实所见即所得富文本文档编辑。用户明确要求文档、媒体等仅保留页面内存，刷新或离开后丢失；评论、数据库视图和多人协作仅预留前端接口，不实现业务或模拟远端同步。保留 Enter 换行、Shift+Enter 拆分块、聚焦内容边框和悬浮块操作入口。

## 总体设计

采用基于 ProseMirror 的 BlockNote 内核及其开源 React/Mantine 视图，复用成熟的选区、格式、撤销重做、块、表格、剪贴板和输入法支持。项目许可策略将 MPL-2.0 列为有条件允许；不修改其源码，依赖许可证检查。编辑器在客户端独立加载，保留既有认证和右下角机器人。文档状态驻留编辑器实例；临时媒体由页面持有 object URL 并在卸载时释放，既不上传也不持久化。英文及中文使用框架对应词典及现有翻译系统。未来评论、数据库和协作使用显式类型接口，无假实现或假连接状态。

## 实施计划

### 阶段一：依赖与页面编辑器
- **文件**：`frontend/package.json`、`frontend/bun.lock`、`frontend/app/colsland/_components/block-editor.tsx`、必要的客户端包装及样式。
- **逻辑**：集成 BlockNote，支持常见内联格式、链接、标题、引用、各种列表、表格、代码块、图片及媒体、拖动和块菜单；保留标题、丢失提醒、主题和响应式布局。文件用 object URL 暂存，卸载释放。
- **验证**：组件及真实编辑器模型中创建和修改富文本、表格与文件；确认组件卸载释放资源。

### 阶段二：交互与未来接口
- **文件**：编辑器组件、`frontend/app/colsland/_components/` 内类型文件、翻译文件和生成类型。
- **逻辑**：用编辑器扩展接管按键并保留输入法安全行为；块边框仅在正文并且不包括悬浮操作；声明评论、数据库视图和协作前端契约但不提供假实现。
- **验证**：选区中 Enter/Shift+Enter、IME、列表和表格行为，块操作及样式边界；中英翻译一致。

### 阶段三：回归与交付
- **文件**：编辑器测试、页面测试、`CHANGELOG.md`、本计划和 `docs/IMPLEMENTATION_PLAN.md`。
- **逻辑**：删除旧 textarea 专属实现及过时测试；验证认证与页面导航不变。
- **验证**：Bun 定向测试、真实内核 DOM 冒烟、TypeScript、ESLint、翻译与许可证检查；不启动服务或浏览器，明确报告视觉及真实浏览器输入法限制。

## 测试策略

- 正常：格式、块类型、文本选区、撤销重做、表格、菜单、媒体、键盘。
- 错误与边界：媒体 URL 清理、多个实例隔离、空块、选区拆分、输入法组合、离开后丢失、认证。
- 回归：现有 Colsland 路由、机器人位置和双语主题。


## 验证与授权记录

- 富文本与链接、表格数据、撤销重做、Enter 换行和 Shift+Enter 拆分通过真实编辑器模型测试；认证页面回归测试通过，合计 4 项。Happy DOM 实际渲染编辑器并点击新增块；临时图片 object URL 插入通过冒烟。
- 前端生产构建、TypeScript、ESLint 和翻译检查通过；未启动服务或浏览器，实际视觉、拖放及真实输入法交互未验证。
- `@blocknote/core`、`@blocknote/react`、`@blocknote/mantine` 0.57.0 使用 MPL-2.0；项目策略列为有条件允许。递归检查所选包已安装普通依赖的 package.json：其余为 MIT、0BSD 或 MIT/CC0 双许可。未将该检查称为完整法律审核；发布还需确保涵盖可选依赖及许可证义务。

## 风险与缓解

- 富文本内核和 UI 包增大体积：按客户端页面加载并避免引入后端运行时。
- MPL-2.0 是项目条件许可：不复制或修改库源码，执行依赖许可检查；发布时遵守其适用义务。
- 页面内存丢失：保留醒目标记，不声称自动保存或协同。
- 回滚：移除依赖和编辑器接入，恢复旧编辑器提交；没有数据迁移。
