# 登录与注册

本指南说明如何通过登录和注册访问 Clouisle。

## 注册方式

Clouisle 支持自助注册（由管理员启用）。

### 自助注册

**步骤：**

1. 访问登录页面：`https://your-domain.com`
2. 点击**"注册"**或**"Sign Up"**
3. 填写注册表单：
   - **用户名**：唯一标识符（最多 50 个字符）
   - **邮箱**：有效的电子邮件地址
   - **密码**：强密码（8+ 字符，见下方"密码要求"）
   - **确认密码**：重新输入密码
4. 如果显示人机验证，请点击**"点击验证您是真人"**
5. 点击**"注册"**
6. 检查您的邮箱以获取验证链接/验证码（如果启用了邮箱验证）
7. 完成邮箱验证以激活您的账号
8. 使用您的凭据登录

**注意**：第一个注册用户会自动成为超级管理员。如果需要管理员审批（`require_approval`），您会看到账号待审批的消息，管理员会收到全局通知。新用户可能会被自动加入配置的默认团队。

> **Note:** 没有基于邀请的注册流程。用户通过自助注册、管理员（管理后台用户管理）创建，或通过 SSO 自动开通（当启用 `sso_auto_create_users` 时）加入系统。

## 登录方式

### 密码登录

**步骤：**

1. 访问登录页面
2. 输入您的**用户名**或**邮箱**
3. 输入您的**密码**
4. 如果显示人机验证，请点击**"点击验证您是真人"**
5. 点击**"登录"**

**安全功能：**
- 多次登录失败后账号锁定（默认 5 次，锁定 15 分钟）
- CAPTCHA 验证（如果启用）
- 会话超时保护
- TOTP 双因素认证（如果启用）

### SSO（单点登录）

如果您的组织配置了 SSO，您可以使用企业凭据登录。

**步骤：**

1. 访问登录页面
2. 点击 SSO 提供商按钮（例如"使用 Google 登录"、"使用 GitHub 登录"）
3. 使用您的 SSO 提供商进行身份验证
4. 您将被重定向回 Clouisle 并自动登录

**首次 SSO 登录：**
- 如果您的邮箱匹配现有账号，SSO 连接会自动关联到该账号（默认启用邮箱匹配）
- 如果不存在账号，将自动创建新账号（如果启用了 `sso_auto_create_users`）

**支持的 SSO 提供商：**
- OAuth2/OIDC（Google、GitHub、GitLab 等）
- SAML 2.0（Azure AD、Okta、OneLogin）
- CAS（大学系统）

有关 SSO 配置，请参阅 [SSO 用户指南](./sso-user-guide_zh-CN.md)。

## 首次登录

首次成功登录后：

1. **欢迎屏幕**：您将看到欢迎消息
2. **个人资料设置**：完善您的个人资料信息（可选）
3. **团队分配**：您可能被自动加入默认团队（如果配置了），或由管理员添加到团队
4. **仪表板访问**：
   - 普通用户看到平台界面
   - 管理员看到管理仪表板

## 会话管理

### 会话时长

- 会话有效期由管理员配置的 **会话超时**（`session_timeout_days`，单位为天，默认 30 天）决定——没有"记住我"选项，也没有基于不活动的登出
- **单会话模式**：每个用户只能有一个活动会话（如果管理员启用）——在其他设备登录会使之前的会话失效

### 登出

**手动登出：**
1. 点击右上角的个人资料图标
2. 选择**"登出"**
3. 您将被重定向到登录页面

## 账号安全

### 密码要求

Clouisle 强制执行密码策略（管理员可配置）：

- **最小长度**：8 个字符（可配置）
- **大写字母**：默认必需
- **数字**：默认必需
- **特殊字符**：默认不要求
- **不重复使用**：不能重复使用最近的密码（默认最近 5 个）
- 没有字典/弱密码检查

### 登录安全功能

**账号锁定：**
- 5 次登录失败后（可配置）
- 账号锁定 15 分钟（可配置）
- 如果反复被锁定，请联系管理员

**人机验证：**
- 管理员启用后，登录和自助注册都需要完成验证（首个初始化用户除外）
- 提交前点击验证控件即可完成
- 如果验证失败、超时或加载异常，请重新点击验证控件

**登录异常检测：**
- 系统跟踪您的常用登录位置和设备
- 从新位置登录时通知您（安全通知）
- 如果看到异常警报，请检查通知

### 双因素认证（2FA）

如果您的组织启用了 2FA：

1. 输入用户名和密码
2. 输入身份验证器应用中的 6 位验证码（TOTP）
3. 点击**"验证"**

**设置 2FA：**
1. 打开**个人资料设置**（个人资料菜单）→ **账户** 标签页
2. 点击**"启用双因素认证"**
3. 使用身份验证器应用（Google Authenticator、Authy 等）扫描二维码
4. 输入验证码确认
5. 将备份代码保存在安全的地方

## 故障排查

### 无法访问登录页面

**问题**：登录页面无法加载

**解决方案：**
1. 检查您的互联网连接
2. 验证 URL 是否正确
3. 尝试不同的浏览器
4. 清除浏览器缓存和 Cookie
5. 联系您的 IT 管理员

### 忘记密码

**问题**：记不住密码

**解决方案：**
1. 在登录页面点击**"忘记密码？"**
2. 输入您的电子邮件地址
3. 检查您的邮箱以获取重置链接
4. 点击链接并输入新密码
5. 使用新密码登录

详见[密码管理](./password-management_zh-CN.md)。

### 账号被锁定

**问题**：登录失败多次后显示"账号已锁定"

**解决方案：**
1. 等待自动解锁（默认 15 分钟）
2. 联系管理员立即解锁
3. 如果忘记密码，使用密码重置

### 未收到验证邮件

**问题**：没有收到验证邮件

**解决方案：**
1. 检查垃圾邮件/垃圾文件夹
2. 等待几分钟（邮件可能延迟）
3. 点击**"重新发送验证邮件"**
4. 验证电子邮件地址是否正确
5. 如果仍未收到，请联系管理员

### SSO 登录失败

**问题**：使用 SSO 登录时出错

**解决方案：**
1. 验证您使用的是正确的 SSO 提供商
2. 检查您的 SSO 账号是否处于活动状态
3. 清除浏览器 Cookie 并重试
4. 联系您的 SSO 管理员
5. 如果可用，尝试密码登录

详见 [SSO 用户指南](./sso-user-guide_zh-CN.md) 了解 SSO 特定的故障排查。

### "账号待审批"消息

**问题**：无法登录，账号待审批

**解决方案：**
- 您的账号需要管理员审批
- 等待管理员激活您的账号
- 批准后您将收到电子邮件
- 如果等待时间过长，请联系管理员

### 会话过期

**问题**：使用过程中显示"会话已过期"

**解决方案：**
1. 重新登录
2. 联系管理员调整会话超时时间
3. 检查是否在另一台设备上登录（单会话模式）

## 最佳实践

### 安全建议

**✅ 应该：**
- 使用强且唯一的密码
- 启用双因素认证
- 在共享计算机上使用后登出
- 保持电子邮件地址最新
- 定期查看登录通知
- 如果可用，使用 SSO（更安全）

**❌ 不应该：**
- 与他人共享密码
- 使用与其他服务相同的密码
- 在公共计算机上保持登录状态
- 忽略登录异常通知

### 账号管理

**定期任务：**
- 在需要时更新密码
- 定期查看登录通知，发现可疑活动
- 保持个人资料信息最新
