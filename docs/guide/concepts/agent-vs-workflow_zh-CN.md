# Agent vs Workflow

理解 Agent 和 Workflow 之间的区别。

## Agent

**对话式和自主**:
- 交互式聊天界面
- 多轮对话
- 自主决策
- 根据上下文使用工具

**使用场景**:
- 客服聊天机器人
- 个人助理
- 问答系统
- 交互式帮助系统

## Workflow

**结构化和确定性**:
- 可视化节点编辑器
- 预定义执行路径
- 显式控制流
- 可重复的过程

**使用场景**:
- 数据处理流水线
- 自动化报告
- API 集成
- 定时任务

## 对比

| 特性 | Agent | Workflow |
|------|-------|----------|
| 界面 | 聊天 | 可视化编辑器 |
| 执行 | 自主 | 确定性 |
| 控制 | AI 驱动 | 用户定义 |
| 使用场景 | 交互式 | 自动化 |
