## [未发布]

### 修复

- 提交 Agent 对话运行时，停用账号会在 API Key 身份处理之前被拒绝。
- 固定个人工具连接的所有者退出团队后，调用现在返回无权使用连接，而不是内部错误。
- 前端兜底错误（无权限、会话过期、超时、网络、服务器错误、资源不存在）改用共享的 `errors` 翻译词条，不再维护第二套硬编码文案；`zh-CN` 等带地区后缀的语言，或未写入语言 Cookie 时，不再回退成英文。

### 新增

- 个人设置弹窗新增「工具连接」页，按当前团队集中列出用户可用的全部连接，展示所属工具、账号标识、范围、默认标记与状态，并支持从工具选择器添加连接、设为默认、重新授权失效账号以及删除连接。无相应权限时不显示入口或操作：该页需要 `tool:read`，团队范围连接仅团队所有者／管理员可管理。

### 变更

- 简化对话中的工具确认卡：用通俗文案说明选择，去除重复状态，并按需展开脱敏操作详情。
- 工具确认面板与输入框上方的参数面板对齐；切换对话时清除上一对话的待确认状态，切回后恢复该对话的待审批操作。
- 对话确认面板在工具提供说明时展示本次调用的工具作用，包括 MCP 子工具说明；此前已暂停且没有记录说明的确认仍可正常处理。
- 修复 Agent 同轮多个工具调用在审批暂停后丢失的问题：未执行的调用按顺序恢复并各自确认，其参数在持久化运行载荷中加密保存。
- 对话中的工具确认面板背景改为透明。
- 工具确认或 ask_user 等待期间，消息和输入区保持运行中状态并提供停止操作；运行结束前禁止编辑、重新生成和切换版本。
- 飞书和微信智能体对话支持调用者通过 `/approve <执行 UUID>` 或 `/reject <执行 UUID>` 确认工具调用；`ask_user` 仍使用独立回答流程。升级时同时更新 API 及全部 Agent／渠道 worker；回滚前完成或停止待审批的 IM 运行。
- 已认证的飞书和微信智能体对话可自动选择调用者的个人工具连接；团队账号仍需明确绑定。

- 移除团队能力页面的网页搜索提示及配置入口；网页搜索由站点管理员在后台配置。

- 工具配置改用调用前确认开关；已有拒绝策略继续禁止调用，直到管理员明确修改。MCP 单项规则保留继承及已有拒绝覆盖。

- 工具执行审批改为仅由调用者确认。交互式 Agent 对话会为发起调用的用户暂停，且只有该调用者可以批准或拒绝一次；团队成员、团队管理员和超级管理员都不能代为决定，原“指定用户”和“团队角色”审批人设置不能再创建或保存。已保存的遗留 `user`/`team_role` 策略（包括嵌套的 MCP 操作覆盖）原样保留，但会在工具执行前以 `6510` 失败关闭，绝不会变成调用者确认或放行；管理员需要重新保存这些策略。升级时会取消所有与外部关卡关联且尚未开始的执行（等待确认或已就绪，包括外部关卡已批准的任务）及其待处理关卡，且不会恢复执行；执行中和已进入终态的记录保留供审计。工作流、工具测试、获取列表、API Key、嵌入、遗留渠道来源和定时入口仍不弹出确认，其中的遗留外部审批配置会失败关闭。回滚应用不会重新激活已取消的执行，请重新发起运行。
- Agent 运行遇到工具权限不足、缺少连接或连接未登录时，返回指明具体工具名称的本地化提示，引导开通权限或在连接设置中登录。
- MCP 请求头和环境变量模板输入 `{{` 时，可补全已声明的连接字段名。
- MCP HTTP 和 SSE 请求头的值在编辑时可见，便于查看连接字段模板；连接凭据仍保持遮罩。
- 精简工具连接卡片：移除内部凭据字段名称，操作按钮在窄屏下自动换行；账号标识和管理操作保留。
- 修复 macOS Celery prefork 子进程调用 MCP 时，系统证书验证触发 Objective-C `SecPolicyCreateSSL` fork 崩溃：未显式指定 CA 文件或目录时使用 `certifi` CA 证书包，保留 TLS 验证；显式 CA 配置和 Linux 行为不变。
- Agent 工具和手动工作流工具节点的个人／可选身份默认自动使用当前用户连接：优先默认账号，否则使用唯一个人账号。多个账号需设置默认；缺少连接或授权失效时提示配置／登录，不借用其他账号。编排仍可固定连接，后台入口仍要求固定连接；MCP 子工具发现与实际执行均使用当前运行用户的凭据。
- HTTP 工具支持 URL 变量模板，替换后校验最终目标的 SSRF 安全性，并在请求配置中提供变量补全。Python 和 JavaScript 代码工具通过每次执行独立的 `credentials` 映射读取所选连接字段，沙箱队列只传递加密凭据。数据库查询改为通过个人/团队连接使用的内置工具，不再创建专用数据库类型的自定义工具，并迁移已有定义与绑定。
- 升级时需同时更新 API/Agent 与 Sandbox Worker，并使用相同工具密钥环；旧密钥需保留到队列中的沙箱任务排空。数据库迁移保留历史工具记录与连接 ID，原子更新当前及版本化定义，并保守保留禁用状态和审批限制。默认连接冲突或单个 Agent 绑定多个同引擎数据库时会停止迁移，不会静默切换身份；请先在旧版本中处理再升级。代码编辑器“运行”不使用连接，保存后的工具“测试”可选择连接。
- 移除独立的工具连接委托授权及其接口和数据模型。在 Agent 或工作流定义中选择连接，即授权该定义在共享或后台运行时使用对应身份；保留配置时绑定校验、个人连接仅所有者可选、凭据隔离以及运行时的连接与团队校验。
- MCP 工具列表与审批规则区域增加响应式最大高度（400px 与 45vh 取较小值），超出后内部滚动；标题和手动添加规则入口保留在滚动区域外。
- 修复 MCP 自动发现 OAuth 后已授权连接仍未附加认证头的问题：即使 `mcp_config.oauth` 缺省或为空，获取列表和实际调用也会使用所选连接的 OAuth 凭证，并保留权限、刷新和版本检查。
- 工具 OAuth 连接支持服务端声明的超过七天的令牌有效期，不再误报为“未返回可用令牌”；仍拒绝非正数和会导致时间溢出的有效期。
- 平台端与管理端 MCP 编辑器将工具名称、简介和审批选项合并为一份列表。当前发现结果中不存在的已保存规则归入“其他操作规则”，刷新工具列表不会删除规则。
- MCP 工具简介保留两行预览，悬浮或键盘聚焦时通过共享 shadcn Tooltip 显示完整内容，不再提供展开按钮或折叠箭头。
- 修复对话中“MCP 服务端请求”面板随后台空列表轮询反复闪现的问题：仅存在真实待响应请求时显示，空列表加载和错误不再占用对话界面。
- 修复交互式 Agent 对话中 MCP 子工具审批规则被忽略的问题；获取列表、调试和工作流仍不触发审批。MCP 调用详情收纳在思考过程内，不再用流式片段工具名反复替换思考栏标题。
- 工具域密钥（工具连接、审批执行参数、OAuth client secret/PKCE、交互响应）改为带版本的封套加密（`enc:tool:v1:<key_id>:…`），密钥环由 `TOOL_SECRET_KEYS` 与 `TOOL_SECRET_PRIMARY_KEY_ID` 配置。旧单密钥密文继续可解密，可用 `python -m app.core.tool_secret_rotation`（支持 dry-run、逐行 CAS）轮换。参见[环境变量](deployment/environment-variables.md#tool_secret_keys)。
- 登录身份源、邮件、Webhook 与飞书手动通讯录同步统一为 Integration，通过 `/site-settings/integrations` 管理，能力静态声明，login/settings 权限分域。
- 管理 API 改为 `/api/v1/admin/integrations`，公开登录发现改为 `/api/v1/sso/integrations`；保留登录/回调地址、UUID 和身份绑定。凭据加密存储，管理响应不返回凭据。
- Schema 切换前须备份数据库与匹配的 `SECRET_KEY`；回滚须恢复匹配的数据库和应用版本，详见[升级说明](admin-guide/settings/SSO_zh-CN.md#现有部署升级)。飞书集成另提供可选的登录能力（`user_login`），详见[配置飞书登录](admin-guide/settings/SSO_zh-CN.md#配置飞书登录)。
- 新增可选的飞书通知集成能力。管理员可向明确选择的已绑定用户发送测试消息；通知通过异步任务发送，并为已绑定的活跃接收者记录各渠道状态。
- 微信 iLink 纳入集成目录，分别控制“智能体对话”和“知识库采集”；个人扫码授权与用途仍由用户管理。关闭功能暂停收件、执行和未发送回复，保留历史与待处理记录。
- 飞书长连接由现有消费 `agent` 队列的 worker 自动托管，支持运行状态、动态启停、配置轮换与单主故障恢复，无需新增服务或接收命令；保留 HTTP 回调模式。
- 修复飞书定时恢复任务的导入作用域错误（`NameError`），恢复已持久化收件及已完成收件的待投递回复处理。
- 微信轮询／恢复及飞书 Agent 恢复改为动态 Beat 调度，后台保存功能开关后通常两秒内增删对应任务，无需重启 Beat。飞书知识库同步仅在集成启用且存在启用的同步源时派发，不受其他能力开关控制。升级时需重启一次 Beat 加载新调度器；已入队任务仍检查当前功能状态。
- 微信轮询由普通 worker 的 `default` 队列执行有界批次，不增加专用服务；保留到期公平领取、持久化租约、全局背压、HTTP 连接池及空消息不派发业务任务。轮询与其他任务共享 worker 槽位。大规模启用前按升级指南并发建立索引。
- 在飞书智能体对话配置页常驻显示中英文必需配置清单，明确私聊接收/发送与身份查询权限、事件订阅、应用发布和审批要求，并说明 WebSocket“已连接”不代表消息已就绪。
- 飞书回复智能体改为各用户在“个人设置 → 飞书”自行选择，与 `/use` 共用配置；后台仅管理通道。按用户迁移已有会话选择，切换不重定向已接收消息或正在执行的任务。
- 个人飞书设置新增立即保存的“启用智能体对话”开关，与后台共享通道开关独立；关闭后保留选择与历史，暂停收件、待处理消息和未发送回复，仅影响本人。
- 精简个人飞书设置：只显示优先级最高的一项配置提示，使用说明移到“回复我的智能体”旁的帮助图标，悬浮或聚焦时显示，不再与保存操作同行；明确开关自动保存、关闭期间消息不补处理、切回智能体延续原会话及中英文命令。
- 压缩微信 iLink 布局：扫码授权与刷新合并到标题栏，连接卡片收紧留白，用途摘要与操作同行，配置表单宽屏双列、窄屏单列；移除智能体运行和采集记录区域及其请求，保留当前任务状态、停止操作、帮助 Tooltip 与后台历史数据。
- 对齐个人飞书与微信 iLink 的配置卡片、留白、按钮尺寸和保存操作顺序，保留各通道原有功能与帮助 Tooltip。
- 个人设置中的“微信互联”更名为“微信 iLink”，同步中英文页面标题与指南。
- 微信 iLink 新增 `/智能体`（`/agents`）与 `/使用 <编号>`（`/use <number>`），复用个人配置和已发布智能体权限校验；忙碌时拒绝切换，保留已接收消息绑定与各智能体会话，提供必填变量配置提示及持久化中英文回复。
- 补全个人飞书与微信 iLink 使用说明 Tooltip，逐项说明各机器人支持的命令及作用。
- 在“账户安全 → 关联账号”新增已有账号绑定飞书的真实入口，支持授权、同标签页确认、发起账号校验与身份冲突拒绝，修正此前仅有文案而无绑定入口的问题。
- 通讯录同步排除通过“账户安全”手动绑定飞书的用户，不重复导入、不覆盖资料、不新增部门团队成员关系；普通通讯录用户继续同步。绑定来源不受后续登录影响，升级时依据保留的绑定审计记录回填。
- 团队所有权转让现在会写入审计日志，记录转让前后的所有者，并标明实际操作者，包括超级管理员。
- 修复微信智能体首次提交误用重派退避而延迟入队的问题；收件完成、最终回复投递记录和会话占用释放改为同一事务提交，写入失败时整体回滚并保留恢复入口，避免模型已回复但微信没有最终消息。升级后须重启所有普通 Celery worker；历史上已标记完成却缺少最终投递记录的消息需显式对账，不会自动补发。
- 微信智能体对话将一次 `getupdates` 响应内相邻的普通消息合并为一次提示，文字与附件一起提交，只执行一次、回复一次；保留原消息去重身份，合并收件关联同一运行但不重复回复。命令分隔分组，等待结构化回答时沿用原流程，不跨响应合并、不增加等待窗口。无需数据库迁移，重启普通 worker 后生效。
- 修复飞书文件、图片及富文本消息被静默丢弃的问题；通过消息资源接口下载附件，保存为私有会话资产并提交给 durable AgentRun，遵守智能体附件限制，失败时明确回复。升级时先通过 API 启动迁移收件表，再重启普通 worker 及其托管接收器；此前被忽略的消息需重新发送。
- 飞书与微信长回复在现有 UTF-8 3500 字节限制内优先按段落、行和句子分段；长 Markdown 表格逐段重复表头及分隔行，超长单元格保留列位置续行，长代码块补齐语言围栏。表头本身超限时退回有界纯文本分段。重启普通 worker 后生效，不改变入站消息分组。

#### 管理后台可观测性

- 将管理后台可观测性控制台重构为概览、运行、依赖、队列、基础设施和告警六个视图，统一查看运行结果、追踪详情、模型/工具/检索依赖与运维状态。
- 在持久化 AgentRun 详情中增加有界的工具与知识检索跨度，并在“依赖”视图中汇总工具和检索的成功率与延迟。
- 每个 AgentRun 最多保留 128 个依赖跨度；达到上限时详情会标明追踪已截断，历史运行不会回填这些数据。
- 为所有已持久化的 AgentRun 生命周期状态补齐中英文翻译，并在遇到未来新增状态时安全回退为原始状态值。
- 为基础设施依赖增加有界的 PostgreSQL、Redis、Celery Worker 与 Qdrant 连通性探测，展示实测延迟，并区分不可用与未配置状态。
- 新增每分钟执行的单主 AgentRun 终态摘要对账，按有界批次修复过期的状态、时间、模型与 Token 字段，不重放运行；修复导致终态摘要丢失的 ORM 查询。
- 模型依赖卡片会将已有遥测中的 UUID 解析为配置的模型名称与供应商展示名称，支持自定义网关名称，并保留同名模型各自的统计。
- 使用独立 Celery inspector 并发采集运行任务、预取任务、定时任务与活跃队列，降低队列快照延迟，保留现有缓存与异常降级行为。
- 并发采集基础设施健康状态与慢查询统计，并将 Celery 回复收集窗口缩短至 0.5 秒，降低快照延迟，保留现有探测截止时间、异常降级和缓存行为。
- 新增 Redis 共享 API 实例发现，通过实例级上报租约去重，展示可读名称、主机资源采样及过期/离线状态；基础设施面板统一列出各后端的保留实例，不再只显示当前请求命中的实例。
- 为可观测性增加双月日历范围选择器，在弹层底部提供滚动时间预设，支持按本地时区覆盖完整日期、URL 保留，并为概览、运行列表及依赖统计统一应用 UTC 时间过滤。
- 仪表盘同步采用日历区间选择器，在弹层底部提供最近 7／30／90 天和全部时间快捷项；自定义日期统一过滤趋势、排名、模型用量、工作流摘要及对话／消息／Token 摘要与平均值，其他固定累计指标保持原定义。

#### 模型与工作流
- 新增 TypeSafe AI（`typesafe`）决策模型供应商与 `decision` 模型类型：对 state 提出类型化问题（`choice` / `score` / `noul`），返回带概率分布和置信度的类型化答案。
- 新增决策节点（Decision）：单个类型化问题按答案分支（score 取概率最高的等级），支持兜底分支与可选的置信度阈值。

  - 视觉能力支持

  - 开始/结束节点
  - LLM 节点（支持模型选择和参数调优）
  - 条件节点（分支逻辑）
  - 代码节点（JavaScript/Python 执行）
  - 工具节点（HTTP API、MCP、内置工具）
  - 迭代/循环节点
  - 变量赋值/聚合节点
  - 子工作流节点
  - 问题分类器节点
  - 参数提取器节点

  - 多格式支持：PDF、DOCX、TXT、MD、HTML、CSV、XLSX、JSON、PPTX
