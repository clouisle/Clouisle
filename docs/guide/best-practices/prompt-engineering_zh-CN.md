# Prompt 工程最佳实践

编写有效提示词的最佳实践。

## 核心原则

1. **具体明确**: 清晰、详细的指令
2. **提供上下文**: 背景信息
3. **定义输出格式**: 结构期望
4. **使用示例**: Few-shot 学习

## 系统提示词设计

```
你是一个[角色]，负责[目的]。

你的职责：
- [任务 1]
- [任务 2]

准则：
- [准则 1]
- [准则 2]
```

## 常见陷阱

- ❌ 指令含糊不清
- ❌ 提示词过长（超出 token 限制）
- ❌ 没有示例
- ✅ 清晰、简洁、带示例
